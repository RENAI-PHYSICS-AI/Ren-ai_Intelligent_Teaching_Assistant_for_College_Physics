# 可视化实验核心

本目录复用自同级“仁爱物理竞赛”项目，只保留 Julia/Bonito/WGLMakie 网页实验，不包含原项目的智能体、RAG、提示词、用户数据或打包产物。

- `lissajous/`：李萨如图形的相位差、振幅比、有理频率比和频率失谐实验，默认端口 `9384`。
- `sound_speed/`：回声法、双麦克风时差法、示波器相位差法和驻波法实验，默认端口 `9385`。
- `electron_em/`：电子束圆轨道、亥姆霍兹磁场标定、纵向磁聚焦和汤姆孙交叉电磁场实验，默认端口 `9386`。
- `photoelectric/`：伏安特性与光强、普朗克常量拟合、红限与量子规律、遏止电压判读与系统误差实验，默认端口 `9387`。
- `biprism/`：分波阵面与虚光源、钠黄光干涉条纹、凸透镜二次成像、波长拟合与不确定度实验，默认端口 `9388`。
- `newton_rings/`：等厚干涉与半波损失、读数显微镜单向测量、15 级逐差法、直径平方线性拟合与不确定度实验，默认端口 `9389`。
- `young_modulus/`：光杠杆微小伸长放大、金属丝加载与卸载、力—伸长线性拟合、杨氏模量与不确定度实验，默认端口 `9390`。
- `rotational_inertia/`：扭摆法、三线摆法、平行轴定理验证和复摆拟合实验，默认端口 `9391`。
- `viscosity/`：斯托克斯落球、终端速度判据、有限圆筒修正和多直径拟合实验，默认端口 `9392`。
- `specific_heat/`：混合法热平衡、冷却修正、电加热法和数据拟合实验，默认端口 `9393`。
- `franck_hertz/`：装置与能级跃迁、峰谷曲线、激发电势和不确定度实验，默认端口 `9394`。
- `temperature_sensor/`：Pt100 标定、阶跃响应、电桥补偿和滞后实验，默认端口 `9395`。
- `wheatstone_bridge/`：电桥原理、平衡调节、灵敏度和多比率拟合实验，默认端口 `9396`。
- `hall_effect/`：霍尔电压标定、磁场扫描、线性拟合和不确定度实验，默认端口 `9397`。
- `magnetic_hysteresis/`：磁滞回线、积分器标定、交流退磁和损耗实验，默认端口 `9398`。
- `thin_lens_focal/`：物距—像距法、自准直法、贝塞尔位移法和不确定度实验，默认端口 `9399`。
- `prism_refractive_index/`：分光计调节、顶角测量、最小偏向角法和色散实验，默认端口 `9400`。
- `thermal_conductivity/`：稳态导热、冷却修正、多工况拟合和不确定度实验，默认端口 `9401`。

十八个服务由 `../experiment_hub.py` 按需启动。每个子实验都是独立路由，只初始化当前打开的图形。网页服务使用相对资源与 WebSocket 地址，因此可同时适配本机和局域网访问。

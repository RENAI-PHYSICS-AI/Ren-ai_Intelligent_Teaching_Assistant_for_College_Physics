# 杨氏模量测定参考资料索引

## 1. 专题口径

本目录服务于“金属丝静态拉伸 + 光杠杆法测杨氏模量”实验。主流程是：在弹性限度内逐级加载和卸载，用望远镜标尺或等效光斑读数测量金属丝伸长，测量金属丝有效长度、直径、镜尺距离和光杠杆臂长，再用逐差或线性拟合求杨氏模量并评定不确定度。

本地“教学素材/物理实验”中此前没有可作为课程口径的杨氏模量资料，因此本专题优先采用公开高校讲义建立操作主线，以 JCGM、NIST、ISO 和 ASTM 的官方资料限定术语、数据解释和不确定度边界。教学光杠杆装置不是 ISO/ASTM 材料试验机，不能声称按工业标准完成了标准符合性试验。

## 5. 使用边界

1. 主实验只在弹性区内用金属丝静态拉伸和光杠杆法测 $E$；干涉、电阻、手机传感器或动态法只可作为拓展。
2. 不同讲义的光杠杆可能采用三脚后足、圆柱转轴或激光光点，使用公式前必须确认臂长 $b$ 的几何定义。
3. 载荷应换算为力 $F=mg$，不可把“kg”直接代入以 Pa 为单位的公式。
4. 工业标准用于说明测量原则和误差来源；教学装置不能宣称符合 ISO 6892-1 或 ASTM E111。
5. 金属丝直径以平方进入 $E$，应沿多个位置和互相垂直方向重复测量，并优先检查零误差与丝径不均匀。
6. 结果必须包含单位、标准不确定度或扩展不确定度、覆盖因子和适用的弹性区间；不能只报一个材料表值。

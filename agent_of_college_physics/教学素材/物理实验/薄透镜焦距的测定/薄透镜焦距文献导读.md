# 薄透镜焦距的测定：文献导读

## 1. 从单薄透镜到高斯近轴系统

薄透镜公式常被写成一个孤立等式，但它建立在近轴近似、均匀介质、清楚的符号约定和理想参考平面之上。Gauss 的 *Dioptrische Untersuchungen* 把共轴系统组织为基点理论：物方/像方焦点、主点和节点使多表面系统可以用等效关系描述。对真正的薄透镜，两主平面近似重合；对厚透镜、胶合镜或装在镜筒中的系统，焦距必须从相应主平面定义。

这一点直接解释了教学实验的常见偏差。学生读取的是物标、镜架刻线和屏的位置，而理论中的 $u,v$ 从主平面量起。若把“镜架中心”无条件当作主平面，重复判焦可以非常稳定，但均值仍可能系统偏移。Born 与 Wolf 对基点、孔径和像差的系统处理，是从薄透镜实验走向真实光学系统的经典桥梁。

## 2. Bessel 位移法为何经典

Bessel 1840 年论文提出了通过固定物屏距离和两共轭位置测量焦距的办法。其数学核心是成像方程在交换 $u,v$ 时不变。若总距离 $L=u+v$ 固定，两个根的位置差 $d=|v-u|$，消元后得到

$$f=\frac{L^2-d^2}{4L}.$$

这不是单纯“多一种公式”。它改变了实验的信息结构：同一标尺的固定零点会同时平移两次透镜位置，却不会改变差值 $d$；物屏固定也避免每次重新设置三个元件。代价是必须满足 $L>4f$，两个图像放大率差异很大，而且两次主观判焦仍可能不对称。

Bessel 原始文献与 Gauss 基点理论也提示：对厚透镜，严格条件要涉及两主平面间距。大学实验可按薄透镜处理，但报告应写清近似及镜架参考线。

## 3. 自准直的双程优势与陷阱

平面镜自准直利用光路可逆性。物标位于前焦面时，透镜把发散光变为平行光；平面镜把它反向送回，第二次通过透镜后回到焦面。因为是双程，小离焦会被放大表现为复像不清晰或不重合，自准直常能减少“屏放在哪里”的附加问题。

不过自准直同时耦合轴向与角度调整。平面镜倾斜会使返回束偏转约两倍镜面倾角，造成复像横向移动；透镜倾斜或物标不在光轴上也会引入彗差和不对称。正确顺序是先建立共轴并调回光，再沿轴向比较清晰度。Hecht 的几何光学章节与 MIT 开放讲义可用于复习光路可逆、焦平面和基本光线。

## 4. 方程、符号和放大率的交叉检查

OpenStax 与 MIT 讲义都强调符号约定。实验记录若只写无符号距离，必须明确讨论的是汇聚透镜、实物和实像。否则把虚像距离也当正数代入会得到形式正确而物理错误的结果。

横向放大率 $m=-v/u$ 是很有价值的质量控制量。在 Bessel 两位置中，$u$ 与 $v$ 交换，因此两次放大率之积为 1，像高一个大、一个小且均倒立。如果两个位置看见的像尺寸几乎相同，而 $L$ 又显著大于 $4f$，应怀疑认错焦点、屏面倾斜或并未保持物屏固定。

色差和球差会使“最佳焦点”依赖光源光谱、孔径和清晰度判据。减小孔径可抑制边缘球差并增加景深，却会降低亮度并增加衍射影响。教学实验要把孔径、照明和判焦目标固定，而不是只追求某一次最清晰。

## 5. 焦距、顶焦距与焦度计

ISO 8598-1 规范一般用途焦度计，ISO 9342-1 规范用于校准焦度计的参考透镜。焦度计常测后顶焦度，即后顶点到后焦点距离的倒数；高斯等效焦距则从像方主平面到像方焦点量起。对很薄且形状近似对称的镜片，两者差别可能小；对厚镜片、强弯月镜和组合系统，不能混为一谈。

这两项 ISO 文献在知识库中仅保存公开题录与标准范围，不复制付费全文。它们的教学价值是建立计量语言：测量对象、参考平面、标称值、允许误差和校准方法必须先定义。NBS IR 75-942 则从国家光学测量体系角度讨论焦距、焦度、像质标准与行业溯源，使光具座实验与工程检验衔接起来。

## 6. 不确定度不是重复性的同义词

JCGM 100 要求从测量模型出发。对直接法，若原始输入量就是独立的 $u,v$，可以利用偏导数传播；但实际光具座常记录物标位置 $x_o$、透镜位置 $x_l$、屏位置 $x_s$，其中 $u=x_l-x_o$、$v=x_s-x_l$，同一个 $x_l$ 以相反符号进入两者。这会产生协方差，最稳妥的做法是直接以三个原始位置为输入建立模型。

典型不确定度来源包括：

1. 多次从两侧判焦得到的 A 类重复性；
2. 标尺分辨力、校准和温度膨胀；
3. 镜架游隙与移动方向；
4. 物标和屏有效平面的位置；
5. 光具座共轴、透镜倾斜和屏面倾斜；
6. 主平面未知、透镜厚度和安装方向；
7. 光源光谱、色差、球差与孔径；
8. 拟合或判焦模型选择。

把多次结果的标准差除以 $\sqrt n$ 只能估计均值的一部分 A 类不确定度，不能覆盖主平面和标尺校准等系统分量。扩展不确定度还应说明覆盖因子 $k$。

## 7. 建议阅读顺序

1. 先用 OpenStax 第 2.4 节和 MIT 第 11 章复习薄透镜公式、作图和放大率。
2. 阅读 Bessel 原始论文的相关页，理解固定 $L$、两共轭位置和差分读数的实验思想。
3. 用 Gauss 原著及 Born–Wolf 的近轴成像章节理解主平面和等效焦距，反思镜架参考线假设。
4. 用 Hecht 连接几何成像、光学仪器、像差和实验观察。
5. 用 NBS IR 75-942、ISO 8598-1 与 ISO 9342-1 区分课堂等效焦距、顶焦度、参考透镜和校准链。
6. 最后用 JCGM 100 从原始位置读数建立完整不确定度预算。

# 中文公版老物理教材

本目录保存来自 Wikimedia Commons 正规公共数字馆藏的完整扫描本，主要为清末、民国时期物理教材。原始文件页标注为公版或来自国家图书馆民国文献项目。

1. 萨本栋：《普通物理学》上编扫描本，商务印书馆，573 页。
2. 萨本栋：《普通物理学》下编扫描本，商务印书馆，614 页。
3. 严济慈：《普通物理学》，正中书局，386 页。
4. 酒井佐保著：《汉译最新物理学教科书》，673 页。
5. 《新制物理学教本》，老中文物理教材扫描本。

## 第二批补充（编号 06-15）

6. 夏佩白：《普通物理学》（1932），大东书局，729 页；内容覆盖物性、力学、热学、声学、光学与磁电学。
7. 萨本栋：《普通物理学》（1937 历史分册），商务印书馆，249 页。
8. 萨本栋：《普通物理学》（早期历史分册），商务印书馆，306 页。
9. 萨本栋：《普通物理学》（1934 历史分册），商务印书馆，247 页。
10. 夏佩白：《普通物理学》（1933 版），大东书局，719 页；与 1932 版属于不同馆藏版本。
11. 萨本栋：《普通物理学》上册选本，550 页。
12. 萨本栋：《普通物理学》下册选本，603 页。
13. Duff：《达夫物理学》中文译本，699 页；综合性大学程度物理教材。
14. Wilhelm H. Westphal：《大学物理学》第 2 卷中文译本，244 页。
15. 沈克刚：《物理学实验室》（1948），中华书局，108 页；包含力、热、声、光、电磁实验。

注意：编号 07-09、11-12 与目录中其他萨本栋版本存在内容重叠，保留它们是为了教材史、版本比较和扫描质量比较，并不代表完全不同的五套教材。

说明：这些教材术语、单位制和部分理论表述具有明显时代特征，适合物理学史、教材史和经典物理参考，不宜直接替代现代工科大学物理主教材。

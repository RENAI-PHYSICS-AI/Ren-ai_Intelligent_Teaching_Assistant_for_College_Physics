# 牛顿环参考资料索引

本目录服务于“已知钠黄光波长，用牛顿环测平凸透镜曲率半径”专题。资料选择遵循三条原则：优先高校正式实验讲义、国家标准数据和实验仪器厂商原始手册；题名、作者、年份无法核验时明确写“未署”；只把可公开访问且确有相关内容的 PDF 保存到本地。下列 14 条是围绕约 10 篇目标扩充后的可核验清单。

本校主实验把空气中钠黄光 $\lambda=589.3\ \mathrm{nm}$ 作为已知量，测量第 5、10、15、20、25、30 暗环直径，采用 $m-n=15$ 逐差及 $D_m^2$–$m$ 拟合求平凸透镜曲率半径 $R$。Na I D2、D1 双线只用于高级说明；IGNOU、IITK 等资料中的“已知 $R$ 测 $\lambda$”保留为公式互逆性拓展，不能取代本校主任务。

## 六、使用边界

1. 主实验把空气中钠黄光 589.3 nm 作为已知量，目标是求平凸透镜曲率半径 $R$；D2/D1 双线仅作高级模式。
2. 高校与厂商资料中的装置步骤用于设计和交叉核验，不替代天津仁爱学院现用仪器说明书与实验室安全制度。
3. 年份未署的网页不根据抓取时间、文件元数据或网址猜测出版年。
4. 反射光下中心暗、透射光下图样互补；页面必须标清观察方式。
5. 绝对环半径易受接触间隙影响，主实验的曲率半径反演优先用第 5/10/15 环分别与第 20/25/30 环组成的 $m-n=15$ 逐差，或用 $D_m^2$–$m$ 拟合斜率；测波长仅作拓展。
6. 钠灯涉及高温和预热；镜片只持边缘、避免过压；激光拓展模式禁止直视光束。
7. 课程 PPT 当前是 Git LFS 指针，未取得实体内容前不把其中页码或结论写入本专题知识块。
